# Samir Feikert — Photography Portfolio

Minimalist, continuous-drift photography and motion portfolio for **Samir Feikert** (Trained Photographer based in Düsseldorf, Germany).

Designed with a editorial layout, infinite draggable horizontal image bands, and a monochrome palette.

---

## Tech Stack

- **Framework:** [Astro](https://astro.build/) (Static Site Generation, zero runtime JS overhead where possible)
- **UI & Animations:** React + lightweight CSS animations
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Typography:** Self-hosted Swiss Neo-Grotesque fonts (*Albert Sans*, *Inter*, and *Roboto Mono*)
- **Language:** Pure JavaScript (`.js`, `.jsx`, `.astro`, `.mjs`)

---

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/sfeikert/samir-feikert-portfolio.git

# Navigate into the project directory
cd samir-feikert-portfolio

# Install dependencies
npm install
```

### Development Server

Start the local dev server at `http://localhost:4321`:

```bash
npm run dev
```

### Production Build

Create an optimized static build in `/dist`:

```bash
npm run build
```
